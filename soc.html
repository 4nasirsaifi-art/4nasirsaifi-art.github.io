Localhost SOC Investigation — Nmap, Wireshark & Log Triage

Investigated a Python HTTP server on localhost (127.0.0.1:8000) end-to-end: Nmap scan (999 closed, 8000 open), tcpdump capture (24 packets, 0 dropped), Wireshark analysis (HTTP 4 packets, Follow TCP Stream, GET / 200 OK), and log triage (admin 3 failed logins in 2 min — suspicious, Medium; web log clean — benign).
